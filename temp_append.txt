### tests/ Directory - Unit and Integration Tests

**tests/verify_dataset.py**
Verifies dataset structure. Checks product_manuals.json, parts_catalog.json, and troubleshooting_tickets.json content counts and sample records.

**tests/test_reranker_alone.py**
Unit test for the reranker in isolation. Creates 5 hand-crafted candidate documents (mix of relevant and irrelevant) and verifies that the cross-encoder ranks the most relevant document (squeaking chair) highest.

**tests/test_omniroute_connection.py**
Tests connectivity to the Omniroute LLM service. Sends a hello message and verifies response.

**tests/test_individual_search.py**
Tests sparse_search() and dense_search() individually. Shows top 5 results with document content for two queries.

**tests/test_hybrid_search.py**
Tests hybrid_search() with RRF fusion. Shows top 5 fused results with sparse and dense ranks.

**tests/test_full_rerank_pipeline.py**
End-to-end test of hybrid_search then rerank pipeline. Times each stage and compares pre/post rerank ordering.

**tests/test_full_generation.py**
Full pipeline test: hybrid_search then rerank then generate_answer then validate_citations. Times each stage and reports citation validation results.

**tests/test_sku_rerank.py**
Tests exact SKU query through hybrid search and rerank. Shows RRF scores and rerank scores side by side.

### docs/ Directory - Project Documentation

**docs/requirements.docx**
System Requirements Specification (SRS). Defines:
- FR-01: Hybrid retrieval (dense + sparse)
- FR-02: Exact SKU match with regex preservation
- FR-03: Metadata filtering
- FR-04: Citation grounding
- FR-05: Guardrails and safety
- NFR-P1: Latency targets (p95 less than 350ms retrieval, less than 1.5s generation)
- NFR-P2: Throughput (150 RPS)
- NFR-S1: Scalability (5000+ catalogs, 2M+ chunks)
- NFR-S2: Availability (99.95% uptime)
- NFR-SEC1/2: Security and RBAC

**docs/technical_design.docx**
Technical Design Document (TDD). Specifies:
- Dual-branch retrieval pipeline architecture
- Qdrant dual collection (1536d dense + BM25 sparse)
- RRF formula: RRF_Score(d) = Sum[1/(k + rank_dense(d))] + Sum[1/(k + rank_sparse(d))]
- API contract: POST /api/v1/query/search with filters, top_k, stream

**docs/hybrid_rag_prd.pdf**
Product Requirements Document (PDF - could not be read directly).

**docs/hybrid_rag_implementation_plan.docx**
8-week implementation roadmap across 4 phases:
- Phase 1 (Weeks 1-2): Data Ingestion and Hybrid Indexing
- Phase 2 (Weeks 3-4): Retrieval and Fusion Engine (RRF)
- Phase 3 (Weeks 5-6): Reranking and LLM Integration
- Phase 4 (Weeks 7-8): Testing, Tuning and Deployment

**docs/hybrid_rag_evaluation_plan.docx**
Evaluation framework using Ragas/TruLens. Target metrics:
- Context Recall@5: >= 95%
- Context Precision@5: >= 92%
- MRR: >= 0.88
- Faithfulness: >= 98%
- Answer Relevance: >= 94%
Test dataset: 500 query pairs (150 exact SKU, 150 natural language, 150 hybrid, 50 adversarial)
